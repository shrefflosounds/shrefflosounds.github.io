# Changelog

All notable changes to Sidehop will be documented in this file. Format follows the build counter scheme (`v00000-001`, `v00000-002`, ...).

## [v00000-001] - 2026-10-19
### Added
- Initial walking skeleton and full core creative platformer workbench.
- Dual-mode workflow: snap-to-grid level editing and seamless in-place playtesting.
- Procedural squash & stretch animation engine for custom doodles and imported sprites.
- In-app Kid Pix Art Studio with drawing brushes, wacky stamps, eraser, and GIF/image import.
- Component Inspector for live physics tuning (jump velocity, run speed, bounciness, enemy patrol).
- Procedural Web Audio API sound synthesis (retro chiptune loops, boings, pickups, fanfares).
- Dual-mode video recording via `MediaRecorder` with direct WebM download.
- Universal `.sidehop` JSON package format for level export and import.
- Local markup review server and injection script (`tools/`).
- MIT License, project brief, handoff, and attribution records.
