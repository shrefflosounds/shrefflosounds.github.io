ℹ️ About Sidehop & Credits
Sidehop
2D Platformer Creator & Personalization Studio
Raison d'Être:
Sidehop exists because building and playing your own video games should feel as immediate, tactile, and expressive as finger painting on drafting paper.
John O'Brien Creator & Lead Designer

Game design, audio direction, creative mechanics, and interactive sandbox architecture.
Portfolio: shrefflosounds.github.io • GitHub: shrefflosounds/sidehop

🔒 100% Local-First: All levels, art, and custom assets are created, simulated, and stored right in your browser. No accounts, no trackers, zero remote servers.

Sidehop stands on the shoulders of legendary creative game-making tools and responsive platformers:

Super Mario Maker (Nintendo, 2015) Game Flow & Sandbox UI

Directed by Takashi Tezuka and produced by Shigeru Miyamoto. Inspired Sidehop's seamless in-place playtesting, snap-to-grid entity placement, corner flyout component menus, mystery question blocks, springboards, note blocks, donut drop lifts, and flagpole victory celebrations.

Kid Pix & Kid Pix 3D (Broderbund, 1989/1994) Art Studio & Tactile Feel

Created by Craig Hickman. The guiding spirit behind Sidehop's Art Studio: chunky tactile toolbars, wacky stamps, squishy audio feedback, and the philosophy that creating things should be messy, joyful, and hilarious.

Drawn to Life (5th Cell / THQ, 2007) Personalization & Custom Heroes

Directed by Jeremiah Slaczka. Inspired Sidehop's player personalization: the magical feeling of drawing your own hero and platforms directly into a living physics engine.

WarioWare D.I.Y. (Nintendo, 2009) Micro-Creation & Tuning

Directed by Goro Abe. Inspired the Component Inspector: tactile parameter sliders making physics tuning (gravity, speed, bounciness) accessible and fun for all ages.

Sonic the Hedgehog & Celeste Kinetic Feel & 45° Slopes

Sonic Team (Yuji Naka & Hirokazu Yasuhara) for 45° incline/decline slope momentum and spring mechanics; Maddy Thorson & Noel Berry (Celeste) for coyote time, jump buffering, and snappy platforming feel.

Sidehop is built from scratch with zero heavy frameworks, running entirely on modern open web standards:

HTML5 Canvas 2D Context W3C / WHATWG Standard

Custom-engineered 60 FPS subpixel platformer engine. Features subpixel AABB collision detection, 45-degree slope heightmap physics, dynamic squash-and-stretch matrices, smooth camera lerp tracking, and procedural terrain tile rendering.

Web Audio API Synthesizer W3C Recommendation

Zero-asset procedural chiptune sound generator inspired by Tomas Pettersson's sfxr / bfxr algorithms. Utilizes native Web Audio API oscillators, exponential gain ramps, and procedural white-noise buffers without loading any external sound files.

MediaRecorder Video API W3C Recommendation

Direct 60 FPS canvas video capture pipeline utilizing the MediaStream Recording API to record crisp WebM/MP4 gameplay clips and trigger instant client-side downloads without any server encoding.

Standalone Single-File Web Export Open Architecture

Exports self-contained HTML files with embedded level data, custom painted visuals, and physics configs that run entirely offline in any modern web browser with zero external dependencies.
