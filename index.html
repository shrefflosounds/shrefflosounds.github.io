Sidehop stands on the shoulders of legendary creative game-making tools and responsive platformers:

Super Mario Maker (Nintendo, 2015) Game Flow & Sandbox UI

Directed by Takashi Tezuka and produced by Shigeru Miyamoto. Inspired Sidehop's seamless in-place playtesting, snap-to-grid entity placement, corner flyout component menus, mystery question blocks, springboards, note blocks, donut drop lifts, and flagpole victory celebrations.

Kid Pix & Kid Pix 3D (Broderbund, 1989/1994) Art Studio & Tactile Feel

Created by Craig Hickman. The guiding spirit behind Sidehop's Kid Pix Art Studio: chunky tactile toolbars, wacky stamps, squishy audio feedback, and the philosophy that creating things should be messy, joyful, and hilarious.

Drawn to Life (5th Cell / THQ, 2007) Personalization & Custom Heroes

Directed by Jeremiah Slaczka. Inspired Sidehop's player personalization: the magical feeling of drawing your own hero and platforms directly into a living physics engine.

WarioWare D.I.Y. (Nintendo, 2009) Micro-Creation & Tuning

Directed by Goro Abe. Inspired the Component Inspector: tactile parameter sliders making physics tuning (gravity, speed, bounciness) accessible and fun for all ages.

Sonic the Hedgehog & Celeste Kinetic Feel & 45° Slopes

Sonic Team (Yuji Naka & Hirokazu Yasuhara) for 45° incline/decline slope momentum and spring mechanics; Maddy Thorson & Noel Berry (Celeste) for coyote time, jump buffering, and snappy platforming feel.

Sidehop is built from scratch with zero heavy frameworks, running entirely on modern web standards:

HTML5 Canvas 2D Engine Graphics & Physics

Custom-engineered 60 FPS subpixel platformer engine. Features subpixel AABB collision detection, 45-degree slope heightmap physics, dynamic squash-and-stretch matrices, smooth camera lerp tracking, and procedural terrain tile rendering.

Web Audio API Chiptune Synth Zero-Asset Sound Synthesizer

Procedural chiptune sound generator inspired by Tomas Pettersson's sfxr / bfxr algorithms. Generates real-time square-wave melodies, frequency-swept jump boings, white-noise impact thuds, and fanfare chimes without loading external audio files.

MediaRecorder API In-Browser Video Capture

Direct 60 FPS canvas video capture pipeline allowing users to record crisp MP4 / WebM gameplay video clips and download them instantly with zero server encoding.

.sidehop File Architecture & LocalStorage Storage & Portability

Portable custom JSON package format (.sidehop) for level sharing, drag-and-drop bundle imports, undo/redo state history, and offline client persistence.

Space Grotesk & Fredoka Typography

Space Grotesk by Florian Karsten — sharp, modern brutalist geometric type.
Fredoka by Milena Brandao — warm, friendly, rounded display typography full of personality.

Neo-Brutalist Toy Workbench Visual Language

High-contrast ink borders (#121212), tactile compressed drop shadows, cheerful canary yellow (#FFE600), cyber cyan (#00E5FF), bubblegum pink (#FF3388), and mint green (#00E676) accents.

Glyphs & Iconography Icons

Custom SVG vectors and universal Unicode Consortium emoji glyphs for cross-platform visual clarity.

Antigravity (Google DeepMind) AI Architecture Partner

Assisted with code architecture, physics slope integration, refactoring, single-file bundling pipelines, and accessibility hardening. All creative concepts, aesthetic choices, sound direction, and game design authored and directed by John O'Brien.

Open Web & Indie Game Creators Community

Warm gratitude to the global indie web game development community, MDN Web Docs, and creators proving that the open web is an incredible, unconstrained canvas for playful software.
