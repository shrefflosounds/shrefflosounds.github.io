[TAB 2: INSPIRATIONS]
Header:
Sidehop stands on the shoulders of legendary creative game-making tools and responsive platformers:

Inspirations:
1. Super Mario Maker (Nintendo, 2015)
   Role: Game Flow & Sandbox UI
   Description: Directed by Takashi Tezuka and produced by Shigeru Miyamoto. Inspired Sidehop's seamless in-place playtesting, snap-to-grid entity placement, corner flyout component menus, mystery question blocks, springboards, note blocks, donut drop lifts, and flagpole victory celebrations.

2. Kid Pix & Kid Pix 3D (Broderbund, 1989/1994)
   Role: Art Studio & Tactile Feel
   Description: Created by Craig Hickman. The guiding spirit behind Sidehop's Kid Pix Art Studio: chunky tactile toolbars, wacky stamps, squishy audio feedback, and the philosophy that creating things should be messy, joyful, and hilarious.

3. Drawn to Life (5th Cell / THQ, 2007)
   Role: Personalization & Custom Heroes
   Description: Directed by Jeremiah Slaczka. Inspired Sidehop's player personalization: the magical feeling of drawing your own hero and platforms directly into a living physics engine.

4. WarioWare D.I.Y. (Nintendo, 2009)
   Role: Accessible Micro-Creation
   Description: Directed by Goro Abe. Proven proof that playful constraints, bold graphic identity, and micro-tools empower players to become confident game creators.

5. Celeste & TowerFall (Maddy Makes Games, 2013/2018)
   Role: Platformer Kinesthetics & Game Feel
   Description: Designed by Maddy Thorson and Noel Berry. Inspired Sidehop's tactile coyote-time jump buffering, squash-and-stretch air deformation, and snappy deceleration.

[TAB 3: CODE & ENGINE]
Architecture Cards:
1. HTML5 Canvas 2D Context
   Role: W3C / WHATWG Standard
   Description: Custom-engineered 60 FPS subpixel platformer engine. Features subpixel AABB collision detection, 45-degree slope heightmap physics, dynamic squash-and-stretch matrices, smooth camera lerp tracking, and procedural terrain tile rendering.

2. Web Audio API Synthesizer
   Role: W3C Recommendation
   Description: Zero-asset procedural chiptune sound generator inspired by Tomas Pettersson's sfxr / bfxr algorithms. Utilizes native Web Audio API oscillators, exponential gain ramps, and procedural white-noise buffers without loading any external sound files.

3. MediaRecorder Video API
   Role: W3C Recommendation
   Description: Direct 60 FPS canvas video capture pipeline utilizing the MediaStream Recording API to record crisp WebM/MP4 gameplay clips and trigger instant client-side downloads without any server encoding.

4. Standalone Single-File Web Export
   Role: Open Architecture
   Description: Exports self-contained HTML files with embedded level data, custom painted visuals, and physics configs that run entirely offline in any modern web browser with zero external dependencies.

5. Sidehop Core Engine
   Role: MIT License • Open Source
   Description: Copyright © 2026 John O'Brien. Released freely under the permissive MIT Open Source License. Permission is hereby granted, free of charge, to any person obtaining a copy of this software.

2. Fredoka
   Role: SIL Open Font License 1.1
   Description: Designed by Milena Brandao. A friendly, warm, rounded display typeface full of playful charm. Used under the SIL Open Font License, Version 1.1.

3. Neo-Brutalist Toy Workbench
